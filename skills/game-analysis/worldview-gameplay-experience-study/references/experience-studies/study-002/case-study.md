# Study 002 — an objective interaction changes the shape of fear

`tags:` infrastructure, water, slow movement, timed escape, route state

## Player voice

I reach a machine because the route makes it feel necessary. Turning the wheel holds my view still, so the action itself feels exposed. Afterward the tunnel is not simply “solved”; water, height, and changed openings make movement slower and the return route harder to read. A battery rule that felt smart in a dry corridor becomes dangerous when I cannot sprint.

Near the end, doors and furniture buy me seconds one at a time. I can see the next obstruction before the current one expires, so the run feels like a chain of choices rather than a corridor with a speed multiplier.

## Critic voice

The design connects objective progress to exposure. The machine is good because it changes what the player must do next, not because it has a complicated interface. Water is effective when it changes the meaning of distance and resource timing; it becomes tedious when every corridor slows the player identically.

## Transfer

Use a tide gate beneath a transit station. The player must stand at the valve while a pressure state changes, then choose a dry shortcut or a slow flooded passage. Put the next obstruction in view before each temporary door delay. Test whether a player can explain the terrain-specific resource rule.

`quality:` effective when terrain changes decisions; weak when it only changes movement speed.
