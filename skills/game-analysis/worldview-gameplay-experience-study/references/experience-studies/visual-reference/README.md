# Visual-reference boundary

The archive uses original abstract plates to explain relationships such as exposure, cover, uncertain sound, failed routes, and recovery. It does not package source-game screenshots, downloaded frames, recognizable maps, UI, character designs, or title-card art.

The shared `attention-route.svg` is a topology legend. It may influence the placement of cues, cover, false branches, and recovery points in a new project. It must not be treated as a source-level reconstruction or as an asset sheet.
