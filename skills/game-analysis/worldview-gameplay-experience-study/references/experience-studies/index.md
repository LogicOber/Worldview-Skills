# Experience-study index

This index is the routing table for de-identified qualitative cases. It is intentionally short. An Agent should load two to five matching cases and one counterexample when available, not read the entire archive before every design task.

## How to route

1. Convert the design brief into concrete tags.
2. Match those tags against the table.
3. Open the selected case's `case-study.md` and `transfer-card.md`.
4. Open only the listed original or rights-cleared visual references.
5. Carry the `study_id` into the working rationale; do not carry source identity or surface details into a new design.
