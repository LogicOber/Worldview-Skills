# Source and authorship boundary

Worldview Gameplay Experience Study is an original research and design method created for this repository. It does not contain copied game code, copied maps, copied dialogue, or a transplanted third-party Skill.

The method separates three things:

1. timecoded observations from a user-authorized study;
2. a clearly labeled, evidence-grounded reconstruction of player experience;
3. an original transfer relationship and verification test for a new project.

Operational analysis may use local media tools, authorized downloaders, speech recognition, image inspection, browser/API access, or a configured classifier. Those tools are acquisition and measurement aids, not sources of design authority. Public case files should contain de-identified study IDs, original prose, original topology diagrams, and rights-cleared or user-owned references only.

Do not publish a source URL, uploader identity, game title, raw transcript, downloaded media, ripped frame, recognizable map, distinctive dialogue, or source-specific asset in a qualitative case file unless the project has a separate written rights and attribution decision. A private operational ledger may retain provenance outside the public Skill package.
