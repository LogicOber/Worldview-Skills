# Source and authorship record

## Origin

This Skill was written for the Worldview Skills repository from the repository owner's request for an end-to-end horror-game workflow. The request emphasized learnable chase routes, architectural planning, lived player experience, audio and visual timing, recovery after failure, optional external tools, and a workflow that lets a user provide a short premise instead of a complete design specification.

## Repository-authored method

The following are original methods authored for this package:

- the five-part horror promise: player question, pressure, decision, consequence, and recovery;
- the experience timeline that keeps source time, player time, and implementation time distinct;
- the chapter rhythm model of orientation, invitation, confirmation, complication, pressure, release, and changed return;
- the threat-knowledge contract and evidence ladder;
- the route-budget and attention-budget checks;
- the mechanic selection matrix and escalation/recovery checks;
- the grey-box-first, state-based verification sequence.

## Boundary

No external code, game map, dialogue, asset, screenshot, prompt, directory layout, or named game scenario is copied into this package. General design knowledge is expressed as new contracts, tests, examples, and transfer rules. Optional image, engine, DCC, API, MCP, and profiling tools are capabilities an Agent may use when already configured and authorized; none is bundled here.
