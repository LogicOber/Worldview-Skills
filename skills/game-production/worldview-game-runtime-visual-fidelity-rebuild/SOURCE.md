# Source and Originality Record

## Repository authorship

`worldview-game-runtime-visual-fidelity-rebuild` is an original production method written for Worldview Skills. It rebuilds the presentation of an already playable game while protecting the behaviors, controls, timing, state, and persistence the user did not authorize the visual pass to change.

Its protected-behavior boundary, named-state comparison model, causal diagnosis, authorization and rights ledgers, calibrated pass sequence, regression journeys, fillable contract, reference material, and fictional Cinderwake example were authored for this repository.

## Research boundary

The user supplied private observations about model-assisted visual production, editable assets, DCC work, runtime capture, iterative review, and the risk of mistaking a polished frame for a finished game. Those observations established the practical problem. They are not public dependencies and are not reproduced or identified in this package.

No external Skill, repository structure, code, prompt, critic role, workflow tree, game, scene, visual identity, asset, screenshot, model, texture, audio, script, validator, schema, manifest, threshold, or provider integration is included or adapted here.

Official product documentation may be consulted at use time for factual model, API, or tool capabilities. Those changing facts do not supply this package's method or expression.

## Original method boundary

This package independently owns:

- recovery of the current playable truth before visual work begins;
- explicit protected behavior and authorized-change ledgers;
- named gameplay states for reproducible before/after comparison;
- causal diagnosis that changes one visual family at a time;
- a visual grammar shared across camera, assets, materials, lighting, effects, interface, animation, and sound;
- separate editable-source, runtime-export, rights, and redistribution records;
- same-state behavioral, visual, temporal, and performance evidence;
- restart, save/load, accessibility, dense-state, and ordinary-play regression journeys;
- fallback behavior when an image tool, DCC, MCP server, browser harness, profiler, or external service is unavailable;
- a truthful handoff that distinguishes improved presentation from unverified gameplay or performance claims.

## Non-copy declaration

All prose, tables, templates, examples, names, values, routes, and verification rules in this package were written for Worldview Skills. The fictional Cinderwake Signal House example is newly authored and is not a representation of an external game.

Future revisions must preserve this boundary: private research can reveal a production failure, but public methods and examples must be independently designed and validated against the user's actual runtime.
