# Source and originality record

This record identifies the commission for `worldview-game-single-ending-campaign`, the repository-authored method created in response, and the material that was deliberately not imported.

## Commission

The Skill was commissioned in the repository conversation on 2026-09-18. The user described a practical one-shot workflow: install the Worldview Skills repository in a new Agent session, provide a short game premise, invoke one Slash command, and receive an English-language 3D story game that can be played through a URL when deployment is available.

The requested game was not a short visual demonstration. It needed one canonical ending; a large-feeling but coherent world; detailed NPCs, objects, and maps; several connected kinds of play; a plot that is interesting in action rather than a sequence of errands; and enough autonomous research that the user would not have to enumerate every current event, community reference, or story beat.

The user also supplied a hypothetical premise inspired by current AI-industry personalities, companies, open-access debates, safety messaging, third-party evaluation, product limits, and online jokes. That premise established requirements for dated research, factual care, satire, and fictional transformation. It is not a story, character set, or allegation adopted by this package.

## Direct source of the method

The method is an original synthesis written for this repository from:

1. the requirements in the 2026-09-18 user commission;
2. this repository’s existing production standards for story-first input, explicit locks, direct runtime evidence, reversible assumptions, source boundaries, and honest delivery;
3. general software and game-production responsibilities independently expressed for a longer single-ending campaign: state ownership, level flow, content budgeting, integration, failure recovery, performance observation, and clean-build verification;
4. generally applicable editorial responsibilities for distinguishing sourced facts, attributed claims, interpretation, community discourse, and invented fiction.

No external Skill was used to generate, outline, rewrite, or validate these files. No Skill generator or `skill-creator` was invoked. The package does not call another Skill at runtime.

## Original decisions introduced here

The following method elements were authored for `worldview-game-single-ending-campaign`:

- a story-only entry point that proceeds from a short premise to research, campaign design, implementation, verification, and deployment when authorized;
- one canonical ending defined as a final irreversible event, final world state, and final meaning rather than merely “one cutscene”;
- backward construction from that ending through a chapter spine and deliberate branch-rejoin points;
- journey variation without ending proliferation: discoveries, tactics, relationships, and resource consequences may differ while the final world state remains singular;
- a density-first campaign budget covering areas, named characters, useful objects, mechanics, state changes, and verification cost;
- an anti-errand rule requiring campaign objectives to alter at least two consequential state families;
- a research ledger that keeps verified facts, attributed allegations, interpretations, community jokes, and new fiction separate;
- a transformation record for themes drawn from real events, with materially distinct fictional identity, appearance, voice, biography, role, setting, chronology, relationships, conduct, and causality;
- a publication-risk gate for close likeness, false attribution, disputed allegations, private information, harassment, logos, copyrighted material, and voice or face imitation;
- linked map, NPC, item, threat, information, chapter, checkpoint, and save-state records rather than independent content lists;
- an interaction portfolio in which every mechanic serves the campaign and is exercised in more than one context;
- complete-route-first implementation, followed by coverage and presentation passes, then clean-build and deployment proof;
- separate evidence for story completion, mechanic behavior, world continuity, branch rejoining, failure recovery, runtime presentation, performance, research, rights, and delivery;
- the default campaign scale described in the README and the rule that scope is reduced before a complete verified route is sacrificed;
- the package’s contract fields, failure analysis, and original worked example.

These are production proposals, not universal empirical thresholds. A particular project may justify different counts or duration while retaining the method’s responsibilities.

## External material deliberately excluded

The user had previously supplied social-post screenshots, pasted commentary, and links to public game or Skill repositories while commissioning other work in this repository. None of those materials was needed as a transformation source for this package. This package contains no borrowed game premise, character, dialogue, code, prompt, asset, screenshot, name, file, data structure, tutorial sequence, production recipe, or distinctive external wording.

It also contains no representation of the real people or organizations mentioned in the user’s hypothetical premise. In particular:

- no living person is renamed by one letter and treated as a new character;
- no real face, voice, biography, quotation, logo, product interface, or company identity is reproduced;
- no user-supplied accusation or interpretation is restated as a verified fact;
- no community joke is presented as evidence;
- no fictional misconduct is attributed to an identifiable real person;
- no disclaimer is represented as automatic protection from publicity, privacy, defamation, trademark, copyright, or other applicable law.

The package teaches a future Agent to research the topic named in the user’s own project, maintain attribution, and transform the subject into original fiction. It does not pre-write the user’s example campaign.

## Research and legal-information boundary

The package does not provide legal clearance. Rights of publicity, privacy, defamation, false light, trademark, copyright, consumer-protection rules, platform policies, and treatment of satire differ by jurisdiction and distribution context. The operational rule is therefore conservative: changing a name, adding a disclaimer, or making an image slightly different is not treated as permission. Recognizable portrayals, disputed real-world claims, biometric imitation, or commercial public release are recorded as review items for qualified jurisdiction-specific advice.

At runtime, current and disputed subject matter must be researched again. Search results, model memory, screenshots, social posts, and popularity counts are not interchangeable with primary evidence. The Agent records publication and event dates, supports each material factual claim with an appropriate source, preserves attribution, notes disagreement, and keeps fictional additions in a separate ledger.
