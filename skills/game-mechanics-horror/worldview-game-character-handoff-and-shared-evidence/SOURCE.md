# Source and originality record: character handoff and shared evidence

## Commission

`worldview-game-character-handoff-and-shared-evidence` was authored for the Worldview Skills repository as an original, all-English Agent method for games in which playable characters hand off control while sharing consequential evidence and world state.

## Method source

The method was distilled from the user's private qualitative research into recurring implementation failures: viewpoints may duplicate one object, know facts they never received, erase earlier actions, mislabel presentation as truth, or corrupt saves during handoff. The private research materials and their identities are not part of this package.

## Strict non-copy boundary

No external game's title, creator, character, place, plot, dialogue, distinctive prop, route, puzzle, UI, art, screenshot, transcript, timing, code, file structure, or published Skill is reproduced or identified. The package does not invite recreating a researched work. Its ledgers, lock sequence, transaction order, template, tests, and fictional example were written for this repository.

The original example **Orison Flood Archive** is fictional. It must not be treated as evidence of an implemented game.

## Repository-authored decisions

Original contributions include:

- the cross-viewpoint handoff ledger and its versioned pointers to truth, physical custody, knowledge, and presentation owners;
- stable shared IDs across viewpoint instances;
- action-to-residue contracts;
- the atomic ten-step viewpoint switch;
- mandatory versus optional knowledge delivery;
- skip-safe and replay-safe ownership rules;
- explicit failure scope and convergence locks;
- debug comparison of truth, holder, knowledge, and presentation;
- the package name, Slash invocation, template, reference, and verification journeys.

## Self-contained boundary

The Skill requires no external Skill, engine, API, asset, or service. It can hand off to neighboring installed Skills, but all instructions needed to apply this ownership method are contained here.
