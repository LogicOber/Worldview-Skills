The general safe-room pattern is common across horror and survival design. This repository does not claim ownership of that broad idea. It contributes a specific, independently written method for pressure classification, atomic entry, threat reconciliation, service transactions, persistence, fair exit, and verification.

## Original synthesis decisions

This package makes the following method choices:

1. “Safe” is decomposed into immediate, local, resource, progress, and strategic pressure instead of treated as global invulnerability.
2. Each pressure explicitly clears, pauses, changes, or persists.
3. Crossing the refuge boundary is an authoritative transaction with an exact damage-resolution point.
4. Threats are reconciled with the exterior world rather than silently deleted or observably teleported.
5. Services and save operations occur only in stable lifecycle states and are protected against duplication.
6. Exiting receives the same design attention as entering, including information, control, and spawn constraints.
7. Rest is allowed to be valuable; anti-camping pressure comes from the existing game structure rather than an unannounced punishment timer.

These decisions are proposals for target projects until implemented and tested there.
