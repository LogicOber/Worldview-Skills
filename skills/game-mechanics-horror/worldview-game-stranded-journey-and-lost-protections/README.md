# Stranded Journey and Lost Protections

Use this Skill when a horror route becomes dangerous by progressively removing mobility, communication, shelter, credibility, navigation, or trustworthy help.

```text
/worldview-game-stranded-journey-and-lost-protections

Design a one-ending courier journey across an evacuated district. Establish a
safe route, working communication, repair access, and public shelter first.
Remove those protections separately, make every help offer cost something, and
corrupt the familiar return path without making the player guess.
```

The Skill produces a journey/resource ledger, segment contracts, safe-return history, help-offer rules, credibility state, fallback paths, save/recovery policy, single-ending convergence, implementation plan, and runtime verification.

Do not use it for a single chase with no longer journey, a generic survival inventory, or an NPC dialogue choice that does not alter access and dependency.

## Neighbor routing

- Chase-route architecture owns an active pursuer's route timing.
- Returning-place escalation owns the changed decision on a particular revisit.
- Role and identity pressure owns an actor's permissions and misuse.
- Asymmetric-information cooperation owns live helper communication and task division.
- Single-ending campaign owns the full campaign and final ending.

Stranded Journey and Lost Protections owns how protections are established, lost, replaced, priced, restored, and carried across route segments.
