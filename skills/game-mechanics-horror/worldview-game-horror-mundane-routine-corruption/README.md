# Worldview Game — Horror Mundane Routine Corruption

Turn ordinary work, travel, study, care, cleaning, cooking, rest, or play into a horror loop the player can understand and test. The player first performs a reliable routine, then notices one exact field change and chooses how to verify, comply, refuse, delay, or leave.

## Call this Skill

```text
/worldview-game-horror-mundane-routine-corruption

Build the opening shift in my riverside seed library. Let the player receive,
weigh, label, shelve, and confirm two normal deposits. On the third deposit,
change only the listed origin while the sealed jar and courier remain familiar.
Make inspection, acceptance, quarantine, and delay alter evidence and routes,
but keep one canonical ending.
```

Use it when horror depends on the player knowing how an everyday process normally behaves. It is not a generic quest list, a decorative job montage, or random anomaly spotting. The routine must establish authoritative state that later play can contradict.

## What the Agent delivers

- a baseline contract across verb, place, person, object, expected result, and confirmation;
- a mastery test and skip-safe teaching path;
- an authoritative state ledger that survives the required save and scene boundaries;
- attention coverage, blind intervals, live timers, and residue rules;
- an exception ladder that changes one field at a time;
- response choices with route, evidence, relationship, resource, or threat consequences;
- recovery, persistence, accessibility, failure, restart, and canonical-ending tests;
- a working loop in the existing runtime when one is available, or an implementation-ready contract when it is not.
