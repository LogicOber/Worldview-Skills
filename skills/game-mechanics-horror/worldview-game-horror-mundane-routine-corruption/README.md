# Worldview Game — Horror Mundane Routine Corruption

Turn serving, driving, studying, sleeping, cleaning, cooking, or playing into a learnable horror loop whose ordinary rule is broken one variable at a time.

## Call this Skill

```text
/worldview-game-horror-mundane-routine-corruption

Build a night café routine. Teach order, prepare, deliver, and close with three
normal customers. Then let one order contain an impossible condition. Give the
player choices to serve, inspect, refuse, or leave, and make each choice change
the next route without creating alternate endings.
```

Use it when everyday work or domestic behavior is the source of unease. It is not an inventory system or a generic quest list; the routine itself must teach the rule that the anomaly violates.

## It delivers

- a normal-loop contract and teaching sequence;
- an exception ladder with player choices;
- customer/room/object state and feedback;
- escalation, recovery, accessibility, and reset tests.

## How the Skill proceeds

It locks **Baseline loop**, **Exception ladder**, **Choice contract**, **Recovery and reset**, **Runtime proof**, and **Handoff** in that order.
