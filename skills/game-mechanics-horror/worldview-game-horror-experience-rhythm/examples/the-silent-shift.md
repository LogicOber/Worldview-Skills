# Example: The Silent Shift

An original fictional example. Invoke it with `/worldview-game-horror-experience-rhythm` when a filled rhythm contract is useful. A night archivist sorts returned boxes in a museum basement. The first contradiction is that a box returns to the wrong shelf after being locked. The peak is a short pursuit triggered by the archivist reading the wrong shelf mark. Recovery is not a safe-room cutscene: the player can re-label the shelf, listen to the ventilation, and choose a route with one box left behind. The ending returns the first shelf mark from the opposite side of the locked archive.

## Completed layer locks

| Lock | Evidence |
| --- | --- |
| Promise | Routine, contradiction, pursuit, recovery, and payoff are named. |
| Beat map | Source and player beats are separated. |
| Attention contract | Shelf, ventilation, and route cues have distinct jobs. |
| Recovery contract | Re-label, listen, and choose are playable recovery actions. |
| Runtime proof | The example is a design case; runtime evidence remains unverified. |
| Handoff | Fictional values are clearly separated from defaults. |

The transferable rule is: let a routine teach a spatial grammar, make one contradiction actionable, attach the peak to the player's interpretation, and let recovery provide a concrete test rather than a full reset.
