# Worldview Game — Horror Returning-Place Escalation

Make a familiar room, street, workplace, or social hub change meaning each time the player returns.

## Call this Skill

```text
/worldview-game-horror-returning-place-escalation

Use the train station as a recurring hub. Each return must change one physical
landmark, one person's relationship to the player, and one available route. Keep
the station learnable, provide a recovery edge, and end with the opening platform
seen from a new side.
```

Use it when a game has repeated locations that currently feel like backtracking. It is not the same as a key-item lock: the change may be social, visual, acoustic, procedural, or informational.

## It delivers

- a stable landmark and return-state ledger;
- a hub graph with altered edges and safe comparisons;
- state-change and relationship rules;
- player-facing cues and recovery routes;
- first visit, return, failure, save/load, and payoff verification.

## How the Skill proceeds

It locks **Stable grammar**, **Return ledger**, **Decision and recovery**, **Persistence**, **Runtime proof**, and **Handoff** in that order.
