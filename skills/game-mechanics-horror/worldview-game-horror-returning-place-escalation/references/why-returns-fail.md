# Why returning places fail

- **Same picture, same meaning:** a return is traversal unless a physical, social, route, or knowledge state changes.
- **Mystery without comparison:** remove too many landmarks and the player cannot tell what changed.
- **Lore-only escalation:** a new speech paragraph is weak if no object, occupant, route, or affordance responds.
- **No recovery edge:** a changed hub can be tense without becoming a maze; preserve one reliable route or anchor.
- **False permanence:** if a changed door or occupant resets unexpectedly, the player cannot learn the place.

Use one changed fact per return before adding more. The player should be able to say what is different and why it matters.
