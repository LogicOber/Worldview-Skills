# Example: The Closed Platform

An original fictional example. Invoke it with `/worldview-game-horror-returning-place-escalation` when a filled return-state contract is useful. A commuter station begins with three landmarks: the clock, the vending machine, and the yellow service stripe. On the first return the vending machine is warm and a new destination appears on the clock. On the second return the attendant recognizes the player's ticket but blocks the public stairs. The service stripe remains truthful and leads to a short recovery loop. The finale places the player behind the clock, where the first platform can be seen as a maintenance route.

## Completed layer locks

| Lock | Evidence |
| --- | --- |
| Stable grammar | Clock, vending machine, and stripe persist. |
| Return ledger | Two returns change object, destination, authority, and route. |
| Decision and recovery | The stripe supplies a reliable recovery edge. |
| Persistence | The fictional state is declared persistent; runtime proof remains unverified. |
| Runtime proof | No build is supplied in this example. |
| Handoff | Values are example-only and not defaults. |

The transferable rule is to preserve a readable anchor while changing one physical and one social fact per return.
