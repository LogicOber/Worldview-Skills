# Relief Resource with Hidden Cost

Use this Skill when a resource should help immediately while creating a separate delayed risk the player can learn and manage. It fits fictional medicine, water, food, rest, comforting rituals, borrowed protection, or any action whose relief and downstream cost must remain different state axes.

```text
/worldview-game-relief-resource-with-hidden-cost

Design a one-ending horror chapter where a blue-room tuning service immediately
steadies the player's distorted hearing, but each use delays door permissions and
leaves a visible trace. Reveal the coupling fairly, support a slower alternative,
and verify cautious, compulsive, and never-use histories through save and reload.
```

The Skill produces a two-axis relief/cost ledger, disclosure schedule, threshold rules, alternative coping path, subsystem handoffs, persistence schema, accessibility plan, implementation tasks, and divergent-history verification.

Use scarce-inventory triage for count, capacity, storage, and transfer. Use wounds, infection, and treatment for physical condition. Use this Skill when the mechanic's core is the learnable coupling between “this helps now” and “this raises a different later risk.”
