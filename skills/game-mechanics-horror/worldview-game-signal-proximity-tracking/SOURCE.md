# Source and originality record

## Commission

`worldview-game-signal-proximity-tracking` is an original synthesis created for this repository in response to the user’s 2026-09-18 request for detailed, all-English Skills covering classic horror-game play patterns. The Skill is designed for direct Claude and Codex loading, a stable Slash invocation, and self-contained use without any Skill-generation tool.

## Originality boundary

No external Skill, commercial game, named character, published level, walkthrough, or distinctive third-party wording was used to create this package. The mechanic was derived from the general design problem of giving a player actionable but incomplete information about an unseen nearby threat.

The fictional scenario **Cairnline Relay**, its setting, device, threat, routes, and example values were authored for this repository. They are illustrative proposals, not evidence from an existing project.

## Problem reconstructed for this Skill

A proximity device is easy to imitate superficially: sample distance and speed up a sound. The repository needs a method that explains the missing causal boundaries:

- which threat state is authoritative;
- which facts the detector is allowed to expose;
- how distance, topology, walls, doors, and interference affect readings;
- how continuous state becomes stable player-facing bands;
- how the player learns to trust incomplete information;
- how success, failure, accessibility, restart, and network authority are verified.

Those questions, not an external implementation, produced the structure of this Skill.

## New decisions introduced here

Original decisions include:

- the public name `/worldview-game-signal-proximity-tracking`;
- separation of world truth, allowed sample, transformed signal, output band, and presentation;
- deliberate selection among Euclidean, path, portal, zone, and hybrid spatial models;
- band contracts with hysteresis, smoothing, response time, and explicit non-information;
- calibration before distortion and distinguishable interference;
- a measurable warning-time versus response-time margin;
- ownership boundaries among threat, map, detector, and encounter;
- equivalent non-audio, non-color, non-haptic, and reduced-motion paths;
- privacy-conscious replication of limited readings rather than automatic exact coordinates;
- the verification matrix and three-file default handoff.

These are method proposals to be validated in receiving projects. They are not claims of universal balance or realism.

## Writing method

The package follows the user-provided Writing 2 approach: restore the problem before prescribing rules, explain why each boundary exists, separate facts from proposals and judgments, retain counterexamples near the claims they limit, and complete the causal explanation before summarizing output.

No text from the Writing 2 archive is reproduced. No skill-creator or Skill-generating Skill was used.
