# Worldview Game — Horror Procedural Duty and Incident

Make the player's job—drive, patrol, rescue, inspect, repair, deliver, or record—the reason an abnormal scene must be approached.

## Call this Skill

```text
/worldview-game-horror-procedural-duty-and-incident

The player is a night road inspector. Teach the inspection checklist, interrupt
it with a collision that has an impossible detail, and make the first objective
verify the detail. Let the player follow procedure, improvise, or retreat while
the same single ending remains reachable.
```

Use it when fear should come from responsibility and evidence, not an immediate monster chase. It composes with entity identification, sound, interrupted puzzles, wounds, and chase routes.

## It delivers

- a job and authority contract;
- a normal procedure tutorial;
- an incident with evidence and uncertain consequences;
- inspect/continue/retreat choices;
- state, audio, route, failure, and ending verification.

## How the Skill proceeds

It locks **Duty and authority**, **Incident evidence**, **Response modes**, **Recovery and persistence**, **Runtime proof**, and **Handoff** in that order.
