# Worldview Game — Horror Procedural Duty and Incident

Build horror around a responsibility the player understands and still has to carry when something goes wrong. The incident does not pause the job and become a cutscene; it forces the player to decide what to inspect, preserve, report, repair, transfer, or abandon while obligations remain live.

## Call this Skill

```text
/worldview-game-horror-procedural-duty-and-incident

Use my night flood inspector. Teach one normal gate inspection, then let the
second gate report a water level that disagrees with the physical gauge while
a downstream warning call is due. Let the player follow procedure, improvise,
or retreat and report. Preserve evidence and partial work through failure and
keep one canonical ending.
```

Use it when a professional, civic, family, or social duty is the reason the player approaches danger. It owns obligation, authority, live work, incident eligibility, response trades, retained work, witnesses, and responsibility shift. It routes detailed evidence, puzzle, sound, wound, chase, or identity behavior to those focused owners.

## What the Agent delivers

- a duty-purpose and authority contract;
- a normal procedure that teaches a route, affordance, relationship, evidence rule, promise, or resource;
- a live-duty snapshot with deadlines, interrupt costs, partial progress, and alternate operators;
- an inspectable incident and observer/witness ledger;
- procedure, improvisation, and retreat/report paths with different local state;
- recovery, persistence, accessibility, save/load, and canonical-ending tests;
- a working encounter in the existing runtime, or an implementation-ready package when no runtime is available.
