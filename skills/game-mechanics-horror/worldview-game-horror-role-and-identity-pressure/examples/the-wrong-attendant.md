# Example: The Wrong Attendant

An original fictional example. Invoke it with `/worldview-game-horror-role-and-identity-pressure` when a filled identity contract is useful. A station attendant proves their role with a brass ticket mark, a route they alone can open, and a repeated closing phrase. The face changes under fluorescent flicker, but the ticket mark remains stable. Trust opens the public gate; questioning reveals a maintenance shortcut; refusal keeps the player safe but leaves the attendant's route active. All paths return to the same final platform.
