# Hero's Journey

Write a quest where the return costs more than the leaving.

## What the user gets

| Deliverable | Format |
|---|---|
| Spine | want · obstacle (outer and inner) · stakes · dilemma · change — per `film-story` |
| Stage map | the 12 stages, each with one line and one tension line, mapped to blocks/chapters |
| Conflict ladder | C1–Cn with setup and payoff blocks |
| Cast | hero, mentor, threshold guardian, shadow, ally, trickster — only the ones the story needs |
| Loss and dilemma | named, placed, unavoidable |
| Emotion map | per block: primary emotion, mechanism, active conflicts |
| Script hand-off | to `film-script`, `visual-novel` or `narrative-choice` |

## Rules this entry enforces

- **The monomyth is a checklist, not a plot.** Stages are used to find what is missing; the story is allowed to skip, merge or invert them.
- **Refusal is real.** The hero says no for a reason the audience shares. A token refusal is a skipped stage.
- **The mentor is lost or wrong.** Somewhere the hero must act without the guide.
- **The ordeal costs something that does not come back.** Per `film-story`: loss is mandatory, and it lands after affection was earned.
- **The elixir is not the treasure.** What the hero brings back changes the ordinary world; the object is a symbol of it.
- **Inner and outer obstacles rhyme.** The gate the hero cannot pass is the fear the hero cannot name.
